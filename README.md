# Lab7Web_PHP

## Pemrograman PHP
#### Tujuan Praktium :
- Memahami konsep pemrograman client-side dan server-side.

- Mengenal sintaks dasar PHP dan cara menjalankannya melalui server lokal.

- Memahami penggunaan variabel, operator, percabangan, perulangan, array, dan function.

- Memahami pemrosesan form menggunakan metode GET dan POST.

- Mempelajari validasi dan sanitasi input pengguna.

- Membuat aplikasi sederhana menggunakan PHP.

#### Perangkat yang Digunakan :
- Laptop/PC.

- Visual Studio Code sebagai editor kode.

- XAMPP sebagai server lokal.

- PHP sebagai bahasa pemrograman.

- Google Chrome sebagai web browser.

#### Cara Menjalankan Server Lokal
1. Membuka aplikasi XAMPP.

2. Menekan tombol Start pada Apache.

3. Membuat folder proyek bernama Lab7Web_PHP di dalam folder htdocs.

4. Membuka folder proyek menggunakan Visual Studio Code.

5. Membuat dan menyimpan seluruh file PHP.

6. Membuka browser Google Chrome.

7. Mengetik alamat http://localhost/Lab7Web_PHP/ untuk menjalankan proyek.

#### Ringkasan 
Praktikum ini menghasilkan beberapa program sederhana menggunakan PHP, mulai dari menampilkan teks, penggunaan variabel dan percabangan, perulangan dan array, function, pemrosesan form GET dan POST, hingga pengolahan data transaksi.

Selain itu, dibuat mini project formulir data mahasiswa yang menggunakan metode POST, validasi input di sisi server, serta fungsi htmlspecialchars() untuk menjaga keamanan output.

Dari praktikum ini, dapat dipahami bahwa PHP digunakan untuk memproses data pada sisi server dan membantu membangun aplikasi web yang dinamis.
