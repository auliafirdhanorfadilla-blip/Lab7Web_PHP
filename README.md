# Lab7Web_PHP

## Pemrograman PHP
### Tujuan Praktium :
- Memahami konsep pemrograman client-side dan server-side.

- Mengenal sintaks dasar PHP dan cara menjalankannya melalui server lokal.

- Memahami penggunaan variabel, operator, percabangan, perulangan, array, dan function.

- Memahami pemrosesan form menggunakan metode GET dan POST.

- Mempelajari validasi dan sanitasi input pengguna.

- Membuat aplikasi sederhana menggunakan PHP.
